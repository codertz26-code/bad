📝 Commands
General
.menu - Show bot menu

.alive - Check bot status

.owner - Show owner info

.ping - Check bot response time

Group Management
.promote @user - Promote member to admin

.demote @user - Demote admin

.kick @user - Remove member

.add 255XXXXXXXXX - Add member

.group open/close - Open/close group

.tagall - Tag all members

.hidetag - Send hidden tag

.link - Get group link

.revoke - Revoke group link

.setname - Set group name

.setdesc - Set group description

Features Control
.antilink on/off - Toggle anti-link

.antidelete on/off - Toggle anti-delete

.autoview on/off - Toggle auto view status

.autolike on/off - Toggle auto like status

.autoreply on/off - Toggle auto reply

.welcome on/off - Toggle welcome message

.goodbye on/off - Toggle goodbye message

.autotyping on/off - Toggle auto typing

.autorecording on/off - Toggle auto recording

Downloads

.instagram <url> - Instagram downloader

Stickers
